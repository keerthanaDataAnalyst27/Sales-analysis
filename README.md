# Sales Analysis Dashboard using Python, Pandas, NumPy, Matplotlib and MySQL

## Project Overview

This project is a Sales Analysis Dashboard developed using Python and MySQL. The dashboard helps analyze sales performance, product revenue, monthly sales trends, top-performing products, and low-performing products through interactive visualizations.

The project demonstrates practical skills in data analysis, database connectivity, data processing, and data visualization.

## Technologies Used

* Python
* MySQL
* Pandas
* NumPy
* Matplotlib

---

## Dataset Information

The dataset contains sales transaction records with the following fields:

* ID
* Date
* Product Name
* Day
* Quantity
* Customer Name
* Price

Products Included:

* Chandrika
* Medimix
* Santoor
* Lux
* Hamam
* Dove
* Mysore Sandal Soap

---

## Project Features

### 1. Data Import and Storage

* CSV data imported into MySQL database.
* Sales records stored in the sales table.

### 2. Sales Analytics

* Total Revenue Calculation
* Average Sales Calculation
* Highest Sales Calculation
* Product-wise Revenue Analysis

### 3. Data Visualization Dashboard

#### Product Wise Sales

* Revenue generated by each product.

#### Month Wise Product Sales

* Monthly revenue comparison across all products.

#### Top 4 Highest Sales Products

* Trend analysis of the highest-performing products.

#### Lowest 5 Sales Products

* Identification of low-performing products.

## Installation

cd sales-analysis-dashboard

pip install -r requirements.txt

---

## Database Setup

Create MySQL Database:

CREATE DATABASE product_db;

Create Sales Table:

CREATE TABLE sales (
id INT PRIMARY KEY,
date DATE,
product VARCHAR(100),
day VARCHAR(20),
quantity INT,
customer_name VARCHAR(100),
price INT
);

Run the Python script to insert and analyze data.
